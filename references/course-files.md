# 文件与续学规范

## 目录与编号

```text
学科名称/
├── 00-前言.md
├── 学习记录.md
├── 01-基础概念/        # 初始化为空
└── 02-核心机制/        # 初始化为空
```

实际复述后，章节中逐步生成 `01-模块名称.md` 等正文。使用 UTF-8 与相对链接；不创建空模块、占位文件或章节 README。

章节 ID 为 C01，模块 ID 为 C01-M01；同一模块持续更新同一文件。重命名修复链接，拆分时新部分使用未占用 ID，阅读顺序写入前言，已有文件和历史不重编号。

一个模块围绕一次或少量会话能讲清的连贯主题。过大、先修跨度大或频繁卡住时拆分/补先修；已具备内容可经简短诊断免重复阅读，但仍需教材覆盖及真实证据。资料不适合时补充或替换，记录调整原因。

## 两个根文档

**00-前言.md**：基础与目标范围、路径依据、资源对比和取舍、费用与估计投入、章/模块目录。每个模块列目标、先修、必学/选学、准确资料位置和检验方式；正文生成后再加入文件链接。

**学习记录.md**：当前位置、阶段、具体断点、已学摘要、下一步；逐模块分别记录阅读、复述、理解验证、内容覆盖、事实核对、文档状态及文件链接。另保留易错点、作者表达档案、核查/纠错/贡献记录和按日期追加的学习轨迹。

当前断点保持简短可直接续接，旧轨迹按需读取。初始状态均未开始；状态改变有用户说明或实际证据。内容补齐、事实核实和用户掌握不能互相代替。

学习记录开头保留课程身份元数据（字符串用 JSON 双引号形式）：

```yaml
---
schema_version: 2
course_id: "生成的UUID"
course_title: "课程名称"
course_root: "实际绝对路径"
created: "用户本地YYYY-MM-DD"
---
```

## 模块正文与保存

模块元数据保留 module_id、title、updated 和 manuscript_status（阶段稿/已整理）。正文按知识需要组织核心原理、用户思考、例子、边界、纠正后的误区、自检与来源，不凑固定空标题。

用简短目标清单检查“资料位置 → 正文位置 → 核对结果 → 用户证据”；关键未核实内容标明待核实。来源放模块，详细学习证据和贡献放学习记录。

保存顺序：模块正文 → 学习记录的状态/断点/下一步 → 前言索引。中断后核对三者，不能假定全部成功；重要误区纠正或目标验证后及时保存检查点。

## 初始化与课程定位

在工作区临时目录准备已研究完的前言和计划 JSON：

```json
{"title":"课程名称","chapters":[{"id":"C01","title":"基础","directory":"01-基础","modules":[{"id":"C01-M01","title":"概念"}]}]}
```

前言须包含章节目录相对链接及全部模块 ID。运行：

```text
python -X utf8 <skill-dir>/scripts/init_course.py --root <新课程绝对路径> --spec <计划JSON路径> --preface <前言Markdown路径> --date <用户本地YYYY-MM-DD>
python -X utf8 <skill-dir>/scripts/course_catalog.py register --root <课程绝对路径> --date <用户本地YYYY-MM-DD>
python -X utf8 <skill-dir>/scripts/course_catalog.py list --query <课程名或course_id>
```

初始化脚本只建架，不代替研究或验收；拒绝已有目录，在临时目录完成后提交，失败可重试。检查两个根文件和空章节后再登记；登记失败只重试登记。

索引在 `$CODEX_HOME/skill-state/systematic-learning/courses.json`；变量未设置时用 `~/.codex/skill-state/systematic-learning/courses.json`。只记录课程 ID、名称、位置与学习根目录，不存学习进度、复述或风格。首次登记设置根目录，以后仅在用户明确要求时用 register 的 `--set-library-root` 改变。

测试可在子命令前指定 `--catalog <JSON绝对路径>`。重名返回多个结果供消歧；路径失效重新定位，移动后保留 course_id、更新 course_root 并重新登记。旧课程先补身份元数据，保留原记录全文。

无 Python 时用文件工具等价创建和维护；无索引访问权限时报告实际限制并保留课程路径，不宣称已登记。课程索引与用户教材不打包进 skill。
