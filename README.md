# 系统化学习与教材共创

把系统学习、复述和教材写作串起来的 Codex skill。

我指定一个学习主题，AI 联网整理完整的路径与资料。我先自学，再把 AI 当学生讲解；AI 核查误解，吸纳我的理解、语气和逻辑，结合可靠资料重新编写教学正文。成稿面向没有参与对话的零基础新学生，概念、原理与例子能在文中独立学懂。学完之后，整个目录就是我自己的系统教材。

复述是写作素材，成品是重新组织的学习资料。它应有我的理解与表达方式，同时具备从零教学所需的完整知识链；不能停留在复述摘要、纠错汇总或复习提纲。

## 使用

将本仓库目录命名为 `systematic-learning`，放入 `$CODEX_HOME/skills`；未设置 CODEX_HOME 时使用 `~/.codex/skills`。

```text
使用 $systematic-learning，我要系统学习【主题】。
我已经学完【模块】，现在我来教你。
继续学习【课程名】。
```

新课程只生成前言、学习记录和空章节。复述后才逐步生成模块正文；进度、误区和作者表达保存在课程目录中，课程位置索引用于跨对话续学。

## 原则

- 资源覆盖完整性优先，随后比较学习效率、便利程度与费用。
- 成稿前必须核查原资料，重要误解纠正后再请我解释。
- 吸纳我的理解与风格，按新学生的认知顺序重编；必要概念、推理与完整例子在正文教清。
- 成稿同时通过事实核对与新读者验收，来源用于追溯和拓展，不替代核心讲解。
- 阅读、复述、理解验证与文档完成分别记录。

需要联网检索与文件读写能力。两个辅助脚本使用 Python 3.10+ 标准库；没有 Python 时也可按文件规范手动操作。

入口：[SKILL.md](SKILL.md)。按阶段读取资料研究、复述成稿和文件规范；仓库不包含个人教材、学习记录或课程索引。
