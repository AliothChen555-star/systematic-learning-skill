# 系统化学习与教材共创

我指定学习主题，AI 联网规划完整路径和资料。我先自学，再把 AI 当学生讲解；AI 核查误解，吸收我的理解与表达，用短句、通俗语言、恰当类比和案例，重编成简短的零基础教材。

成品能让没看过聊天的新学生独立学习。整门课程覆盖完整，每篇只讲当前目标；通常用一个贯穿案例，不堆额外细节。

## 使用

将本仓库目录命名为 `systematic-learning`，放入 `$CODEX_HOME/skills`；未设置 CODEX_HOME 时使用 `~/.codex/skills`。

```text
使用 $systematic-learning，我要系统学习【主题】。
我已经学完【模块】，现在我来教你。
继续学习【课程名】。
```

新课程只生成前言、学习记录和空章节。复述后才逐步生成模块正文；课程索引用于跨对话续学。

## 原则

- 资料完整性优先，随后比较学习效率、便利程度与费用。
- 必须核查来源和误解；纠正后请我重新解释，不把补讲记作已掌握。
- 标题直白，正文短句、通俗易懂；中文单篇通常约800–1500汉字，复杂主题分篇。
- 保留我的有效推理和表达，补齐必要因果，不写成聊天摘要或结论清单。
- 事实核对、教材教清、用户理解分别检查和记录。
- 核心知识讲进正文；资料标明必读、选读或进阶，查证规范不作为初学者的隐含作业。

需要联网与文件读写能力。两个辅助脚本使用 Python 3.10+ 标准库；没有 Python 时按文件规范手动操作。

入口：[SKILL.md](SKILL.md)。仓库不包含个人教材、学习记录或课程索引。
